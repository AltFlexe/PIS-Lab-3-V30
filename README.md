# Лабораторная работа 3 — статьи и аренда помещений

Учебный проект Django выводит архив статей о торговых площадях. Через административную панель можно управлять статьями, помещениями, арендаторами, договорами, периодами аренды и платежами. Один договор может включать несколько помещений с отдельными сроками. Границы периода включительны: для одного помещения пересекающиеся периоды запрещены.

## Запуск

При установленном Python 3.11 из корня проекта в PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/manage.py migrate
.\.venv\Scripts\python.exe src/manage.py loaddata demo
.\.venv\Scripts\python.exe src/manage.py createsuperuser
.\.venv\Scripts\python.exe src/manage.py test articles
.\.venv\Scripts\python.exe src/manage.py runserver
```

Главная страница доступна по адресу `http://127.0.0.1:8000/`, административная панель — `/admin/`. Команда `loaddata demo` добавляет учебные помещения, арендатора, договор, периоды и платёж в новую базу; после этого в панели можно создать статьи. Пример не содержит настоящих учётных данных. Для локального запуска можно задать переменную `DJANGO_SECRET_KEY`; если она не задана, ключ создаётся при запуске и после перезапуска может потребоваться повторный вход.

`src/articles/models.py` содержит модели, `admin.py` — их регистрацию в панели, `migrations/` — изменения базы, `fixtures/demo.json` — учебные данные. Защита от пересечений также действует на уровне SQLite и рассчитана на эту СУБД. Для поиска свободных помещений вызывается `Space.available(начало, конец)` с датами.
